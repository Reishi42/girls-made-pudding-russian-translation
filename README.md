# GIRLS MADE PUDDING — русский перевод

Фанатский русификатор: интерфейс, описания предметов и семь сюжетных сценариев. Все 3429 строк сверены с японским текстом: исправлены смысловые ошибки, грамматика, согласования и имена. Экранная проверка расположения текста в игре пока не выполнена.

## Установка отдельных файлов

1. Закройте игру.
2. Сохраните копии четырёх исходных файлов, перечисленных ниже.
3. Откройте каждую ссылку и скачайте файл кнопкой **Download raw file**. Сохраните исходные имена файлов.
4. Замените файлы в папке игры, соблюдая указанные пути.

В `girls-made-pudding_Data/StreamingAssets/aa/`:

- [catalog.bin](girls-made-pudding_Data/StreamingAssets/aa/catalog.bin)
- [catalog.hash](girls-made-pudding_Data/StreamingAssets/aa/catalog.hash)

В `girls-made-pudding_Data/StreamingAssets/aa/StandaloneWindows64/`:

- [message_assets_all_b383d1e4e5665bf6c6bfef5a757ff215.bundle](girls-made-pudding_Data/StreamingAssets/aa/StandaloneWindows64/message_assets_all_b383d1e4e5665bf6c6bfef5a757ff215.bundle)
- [scenario_assets_all_3b287153570114440836c7573a9166bb.bundle](girls-made-pudding_Data/StreamingAssets/aa/StandaloneWindows64/scenario_assets_all_3b287153570114440836c7573a9166bb.bundle)

Обновляйте все четыре файла вместе: каталог должен соответствовать бандлам.

Русский перевод занимает слот упрощённого китайского языка (`chs`). При первом переключении из английского или японского выберите **简体中文**. После перехода на перевод этот пункт будет называться **Русский**.

## Управление на клавиатуре

- **W, A, S, D** — движение; обозначения латинские.
- **Мышь** — камера.
- **1, 2, 3** — выбор скорости.
- **Shift** — ускорение.
- **4** в верхнем цифровом ряду — автопилот.

В оригинальной пиктограмме цифра **4** похожа на русскую «Ч». Это не буква: нажимать **X/Ч** для автопилота не нужно. В переводе добавлена явная подпись «Автопилот (клавиша 4)».

Если при русской раскладке клавиатура не реагирует, переключитесь на **EN**. Причина такого поведения в игре пока не установлена; этот пакет меняет текстовые таблицы и не исправляет обработчик ввода.

## Откат и совместимость

Для отката верните все четыре файла из своей резервной копии. Сохранения патч не изменяет.

Если резервной копии нет или после установки игра не запускается, восстановите исходные файлы проверкой целостности игры в Steam. После этого русификатор потребуется установить заново.

Патч собран для версии игры из установки автора. После обновления игры совместимость нужно проверять заново.

Последние исправления перечислены в [CHANGELOG.md](CHANGELOG.md), объём проверки — в [REVIEW.md](REVIEW.md).

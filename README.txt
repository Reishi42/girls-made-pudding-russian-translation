Русификатор GIRLS MADE PUDDING

Установка отдельных файлов
1. Закройте игру и сохраните копии исходных файлов.
2. Скопируйте папку girls-made-pudding_Data из этого комплекта в корневую папку игры, подтвердив замену.
3. Заменяйте вместе все четыре файла: catalog.bin, catalog.hash и бандлы message/scenario.
4. При первом выборе языка из английского или японского меню выберите 简体中文 (упрощённый китайский). После переключения пункт будет называться «Русский».

Для скачивания каждого файла с GitHub откройте его страницу и нажмите Download raw file. Подробные пути и ссылки приведены в README.md.

Клавиатура
W, A, S, D (латинские) — движение; мышь — камера.
1, 2, 3 — скорость; Shift — ускорение; 4 в верхнем цифровом ряду — автопилот.
В оригинальной пиктограмме цифра 4 похожа на «Ч». Это не клавиша X/Ч.
Если управление не работает на русской раскладке, переключитесь на EN. Причина этого поведения пока не установлена; обработчик ввода этот пакет не меняет.

Откат
Верните все четыре исходных файла из резервной копии.
Если копии нет или после установки игра не запускается, восстановите исходные файлы проверкой целостности игры в Steam. После этого русификатор нужно установить заново.

Совместимость и состояние перевода
После обновления игры совместимость нужно проверять заново.
Все 3429 строк сверены с японским текстом: исправлены смысловые ошибки, грамматика, согласования и имена. Экранная проверка расположения текста в игре пока не выполнена.

Русификатор GIRLS MADE PUDDING

Установка
1. Закройте игру.
2. Сохраните копии исходных catalog.bin, catalog.hash и двух бандлов из папки игры.
3. Распакуйте содержимое этого архива в корневую папку GIRLS MADE PUDDING и подтвердите замену файлов.

В архиве сохранена структура girls-made-pudding_Data/StreamingAssets/aa/.
Русский текст использует слот упрощённого китайского (chs), который в игре подписан «Русский».

Откат
Верните четыре исходных файла из резервной копии на те же места.

Совместимость
Патч собран для версии игры из установленной копии автора. После обновления игры он может перестать работать. В случае проблем с запуском после установки патчка, восстановите исходные файлы игры инструментами Steam
